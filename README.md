## SpriteDex

## 📌 | 🇺🇸 Description | 🇧🇷 Descrição  
 - 🇺🇸 | A Next.js application built for studying routing, dynamic pages and API integration. It displays Pokémon sprites and descriptions from the official series. Users can browse Pokémon through pagination, filter by generation (Gen 1 and Gen 2), and search directly via URL using the Pokémon Pokédex number. The project was also optimized using Lighthouse tool from Chrome DevTools.
 - 🇧🇷 | Aplicação em Next.js criado para estudo de rotas, páginas dinâmicas e integração API. Exibe sprites e descrição dos Pokémon da série oficial. Usuários podem pesquisar por paginação, filtrar por gerações (1ª e 2ª geração), e pesquisar via URL baseado no número do Pokémon na Pokédex. O projeto também foi otimizado utilizando a ferramenta Lighthouse do Chrome DevTools. 

## 🎯 | 🇺🇸 Project purpose | 🇧🇷 Propósito do projeto 
  - 🇺🇸 | A practical project aimed at improving skills in public APIs, dynamic pages, and optimization using the Lighthouse tool.
  - 🇧🇷 | Projeto prático focado em aprimoramento de habilidades no uso de APIs públicas, páginas dinâmicas, e otimização via Lighthouse.
